# Название проекта![Статус: В разработке](https://img.shields.io/badge/Статус-В_разработке-yellow)![Python](https://img.shields.io/badge/Python-3.12-blue)![Poetry](https://img.shields.io/badge/Poetry-2.x-blueviolet)**TransAN** — это приложение для анализа банковских транзакций из Excel-файлов. Оно генерирует JSON-данные для веб-страниц, формирует аналитические Excel-отчеты и предоставляетсервисы для поиска и фильтрации операций.## Содержание- [Технологии](#технологии)- [Начало работы](#начало-работы)- [Тестирование](#тестирование)- [Deploy и CI/CD](#deploy-и-cicd)- [Contributing](#contributing)- [To do](#to-do)- [Команда проекта](#команда-проекта)## Технологии- **[Python 3.12]** — язык программирования- **[Poetry]** — управление зависимостями- **[Pandas]** — обработка данных из Excel- **[Requests]** — работа с API- **[Pytest]** — тестирование- **[Flake8]** / **[Black]** / **[Mypy]**  / **[isort ]**— линтеры и форматтеры- **[Marketstack API]** — получение цен акций- **[Exchange Rates API]** — получение курсов валют## Начало работы### Требования- **Python 3.12** или выше- **Poetry** (рекомендуется)### Установка зависимостей```bash# Клонируйте репозиторийgit clone https://github.com/svmikhaylov333/TransAncd transan# Установите зависимости через Poetrypoetry install# Активируйте виртуальное окружениеpoetry shell```### Установка зависимостейСоздайте файл .env в корне проекта:```# Marketstack API (цены акций)STOCKS_API_KEY=ваш_ключ_здесьSTOCKS_API_URL=https://api.apilayer.net/marketstack/v2# Exchange Rates API (курсы валют)EXCHANGE_RATES_API_KEY=ваш_ключ_здесьEXCHANGE_RATES_API_URL=https://api.exchangeratesapi.io/v1```###Настройки пользователяФайл user_settings.json:```json{  "user_currencies": ["USD", "EUR"],  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]}```### Запуск приложения```bashpoetry run python main.py```### Линтеры и форматтеры```bash# Форматированиеpoetry run black .poetry run isort .# Проверка стиляpoetry run flake8 .poetry run mypy .```### ТестированиеДля запуска проверки функций:```bashpytest```Дополнительные проверки```bashpython tests/test.py```Для анализа покрытия кода тестами использовать```bashpytest --cov```Сформировать отчет, см. htmlcov/index.html ```bashpytest --cov=src --cov-report=html```## Deploy и
