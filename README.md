# Название проекта![Статус: В разработке](https://img.shields.io/badge/Статус-В_разработке-yellow)![Python](https://img.shields.io/badge/Python-3.12-blue)![Poetry](https://img.shields.io/badge/Poetry-2.x-blueviolet)**TransAN** — это приложение для анализа банковских транзакций из Excel-файлов. Оно генерирует JSON-данные для веб-страниц, формирует аналитические Excel-отчеты и предоставляетсервисы для поиска и фильтрации операций.## Содержание- [Технологии](#технологии)- [Начало работы](#начало-работы)- [Тестирование](#тестирование)- [Deploy и CI/CD](#deploy-и-cicd)- [Contributing](#contributing)- [To do](#to-do)- [Команда проекта](#команда-проекта)## Технологии- **[Python 3.12]** — язык программирования- **[Poetry]** — управление зависимостями- **[Pandas]** — обработка данных из Excel- **[Requests]** — работа с API- **[Pytest]** — тестирование- **[Flake8]** / **[Black]** / **[Mypy]**  / **[isort ]**— линтеры и форматтеры- **[Marketstack API]** — получение цен акций- **[Exchange Rates API]** — получение курсов валют## Начало работы### Требования- **Python 3.12** или выше- **Poetry** (рекомендуется)### Установка зависимостей```bash# Клонируйте репозиторийgit clone https://github.com/svmikhaylov333/TransAncd transan# Установите зависимости через Poetrypoetry install# Активируйте виртуальное окружениеpoetry shell```Создайте файл .env в корне проекта:```# Marketstack API (цены акций)STOCKS_API_KEY=ваш_ключ_здесьSTOCKS_API_URL=https://api.apilayer.net/marketstack/v2# Exchange Rates API (курсы валют)EXCHANGE_RATES_API_KEY=ваш_ключ_здесьEXCHANGE_RATES_API_URL=https://api.exchangeratesapi.io/v1```###Настройки пользователяФайл user_settings.json:```json{  "user_currencies": ["USD", "EUR"],  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]}```### Запуск приложения```bashpoetry run python main.py```Реализованные функции:```Веб-страницы: Главная страница — приветствие, карты, топ-5 транзакций, курсы валют, цены акцийСервисы- Выгодные категории кешбэка — топ-N категорий (1 рубль на каждые 100 рублей трат)Отчеты- Траты по категории — общая сумма по категории за последние 3 месяца (90 дней)  ```Результаты сохраняются в папку output/:```main_page.json — ответ главной страницыcashback_categories.json — топ-N категорий по кешбэкуspending_by_category.txt — отчет по тратам за 3 месяца```Пример выходных данных Главная страница```json{  "greeting": "Добрый день!",  "cards": [    {      "last_digits": "4556",      "total_expenses": 3775.7,      "cashback": 37.76    }     ],  "top_transactions": [    {      "date": "30.12.2021",      "amount": 174000.0,      "category": "Пополнения",      "description": "Пополнение через Газпромбанк"    }  ],  "currency_rates": {    "USD": 78.18  },  "stock_prices": {    "GOOGL": 319.74,    "MSFT": 381.7,    "AAPL": 333.02,    "AMZN": 232.11,    "TSLA": 313.03  }}```Пример выходных данных Сервис (топ-N категорий по кешбэку)```json{  "Переводы": 49420,  "Образование": 6510,  "Наличные": 6324,  "Супермаркеты": 3781,  "Другое": 2456}```Пример выходных данных Отчет по тратам в категории за период``` Отчет по тратам за последние 3 месяца (90 дней)Период: с 02.10.2021 по 31.12.2021Категория: СупермаркетыИТОГО: 421.06 руб.Количество транзакций: 4```### Линтеры и форматтеры```bash# Форматированиеpoetry run black .poetry run isort .# Проверка стиляpoetry run flake8 .poetry run mypy .```### ТестированиеДля запуска проверки функций:```bashpytest```Дополнительные проверки```bashpython tests/test.py```Для анализа покрытия кода тестами использовать```bashpytest --cov```Сформировать отчет, см. htmlcov/index.html ```bashpytest --cov=src --cov-report=html```## Deploy и CI/CDНа текущем этапе CI/CD отсутствует.## ContributingПо вопросам и предложениям
